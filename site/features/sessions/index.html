Features/04 Sessions

Every Claude Code session, across every project

Five sessions, three repos. Know which one is waiting on you.

The daemon reads the transcripts Claude Code already writes and indexes them as they land. A list that tells working from stuck, a detail view that replays the run as a conversation, and a rail with models, agents, files and cost. Nothing to install in your projects.

01 · the list

Working, or only quiet

Every session from every project, newest first. Filter by status: working, waiting, idle, done. Each row shows its branch, model and plan progress, and a live row says what the agent is doing this second.

  • A stuck session shows how long it has been silent
  • Plan runs collapse into one card per plan
  • Filter by status and account
LIVE
02 · the timeline

Every tool call, in order

Chat reads like a conversation with tool calls folded away, and you can reply to the agent right from the dashboard. Timeline shows every tool call, sub-agents and errors. A permission waits right in line: approve it there.

  • Reply from the dashboard to resume a session
  • Sub-agents included in the timeline
  • A waiting session tells you where to answer
LIVE
03 · the diffs

Every file the session changed

Diffs collects every file the session touched, in one place. Changes outside the plan are flagged as out of scope. A handoff brief lets a fresh session pick up where the last one stopped.

  • Out-of-plan changes flagged
  • Models, agents, skills and the call tree in the side panel
  • Handoff brief for a fresh session
