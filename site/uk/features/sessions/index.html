Можливості/04 Сесії

Кожна сесія Claude Code в кожному проєкті

П’ять сесій, три репозиторії. Знайте, яка з них чекає на вас.

Демон читає транскрипти, які Claude Code і так пише, і індексує їх, щойно вони з’являються. Список, що відрізняє роботу від застрягання, детальний перегляд, що відтворює запуск як розмову, і бічна панель із моделями, агентами, файлами й вартістю. У ваші проєкти нічого встановлювати не треба.

Працює чи просто мовчить

Кожна сесія з кожного проєкту, від найновішої. Фільтруйте за статусом: працює, чекає, простоює, завершена. Кожен рядок показує гілку, модель і прогрес плану, а живий рядок каже, що агент робить цієї секунди.

  • Застрягла сесія показує, скільки вона вже мовчить
  • Запуски плану згортаються в одну картку на план
  • Фільтр за статусом і акаунтом
НАЖИВО
02 · хронологія

Кожен виклик інструмента по черзі

Chat (чат) читається як розмова зі згорнутими викликами інструментів, і відповісти агентові можна прямо з дашборду. Timeline (хронологія) показує кожен виклик інструмента, субагентів і помилки. Запит дозволу чекає просто в рядку: погодьте його там.

  • Відповідь із дашборду відновлює сесію
  • Субагенти теж у хронології
  • Сесія, що чекає, підказує, де відповісти
НАЖИВО
03 · диффи

Кожен файл, який змінила сесія

Diffs (диффи) збирає в одному місці кожен файл, якого торкнулася сесія. Зміни поза планом позначено як такі, що виходять за межі задачі. Бриф для передачі дає новій сесії продовжити там, де зупинилася попередня.

  • Зміни поза планом позначено
  • Моделі, агенти, скіли й дерево викликів у бічній панелі
  • Бриф для передачі новій сесії
