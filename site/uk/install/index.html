почати

Три команди — і рій працює.

Не треба ні реєструватися, ні нічого хостити. Маркетплейс встановлюється в Claude Code, скрипт ініціалізації пише оверлей проєкту, а центр керування працює на вашій власній машині.

Додайте маркетплейс і ядро

Усередині Claude Code. Доменні пакети вмикаються поверх за бажанням, див. Плагіни.

/plugin marketplace add atretyak1985/swarmery
/plugin install core@swarmery

Підключіть проєкт

З клону репозиторію, у проєкті, який хочете підключити: скрипт пише settings.json, заготовку project.json і приватний простір імен проєкту в робочому просторі.

bash scripts/init.sh

Встановіть і запустіть центр керування

Скрипт завантажує бінарник релізу для вашої платформи й звіряє його з SHA256SUMS. Демон слухає 127.0.0.1:7777, а сесії, які ви вже запускали, з’являються одразу.

curl -fsSL https://raw.githubusercontent.com/atretyak1985/swarmery/main/scripts/install.sh | bash
swarmery serve

потім відкрийте

127.0.0.1:7777

Today (сьогодні) показує, що чекає на вас, що працює зараз і цикл цього тижня. Почніть план через Plans → New plan (плани → новий план) або просто дивіться, як з’являються ваші наявні сесії.

  • Слухає лише loopback-інтерфейс
  • Дані лишаються в локальній SQLite
  • Працює як сервіс: launchd на macOS, systemd --user на Linux
